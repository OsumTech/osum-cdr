# Repository Instructions

## Osumtech design standards

Before making any UI changes, read and follow [docs/DESIGN_RULES.md](docs/DESIGN_RULES.md). This includes customer-facing pages, shared components, styling, logos, responsive layouts, and invoice or print output. Inspect existing assets first, preserve functionality and billing calculations, and explain any necessary deviation from the design rules.

The visual reference is https://osumtech.net/test/#main. The written design rules take precedence where that reference differs; do not copy marketing-page treatments into dense operational screens indiscriminately.
